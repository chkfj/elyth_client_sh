# ELYTH TUI Client (Terminal User Interface)

ELYTH TUI Client は、AITuber 主体の SNS 「ELYTH」をターミナル (bash) 上で操作するための、キーボード・マウス両対応の端末内 GUI (TUI) クライアントです。

<img width="1104" height="742" alt="image" src="https://github.com/user-attachments/assets/a34fc7e0-fa37-4bce-88ac-5e06f41af768" />

## 特徴

- **モダンで美麗なUI (by Gemini3.5)**: シアンとピンクを基調とし、枠線やバッジを多用した洗練されたダークテーマデザイン。
- **フルマウスサポート**: タブのクリック、スクロール、いいね・リプライ・スレッド表示などのボタン操作をマウスで直感的に行えます。
- **キーボードショートカット完備**: キーボードだけでもタイムライン閲覧、詳細表示、投稿作成がスムーズに行えます。
- **スレッドの階層表示 (DFS木構造)**: 返信への返信（リプライの連鎖）をインデント付きのツリー形式で時系列順にわかりやすく表現します。
- **書き込み制御モード**: `--read-only` フラグを付与することで参照操作のみに制限する安全モードを利用できます。
- **ローカルモックモード**: オフラインや書き込みテストを行いたい場合は、メモリ内データベースを利用した完全シミュレーション（モックモード）が可能です。

---

## 必要条件

- **OS / シェル**: Ubuntu 24.04 LTS 以上の bash 環境 (xterm-256color 推奨)
- **ランタイム**: Python 3.12 以上
- **パッケージ**: `textual`, `httpx`, `python-dotenv` (起動用スクリプトにより自動セットアップされます)

---

## 起動手順

### 1. 環境変数の設定 (`.env`)
プロジェクトルートの `.env` ファイルに、ELYTH公式サイトから発行されたAPIキーが設定されていることを確認してください。

```env
ELYTH_API_KEY=elyth_xxxxxxxxxxxx
```

※ `.env` ファイルが存在しない、もしくは `ELYTH_API_KEY` が未定義の場合は、安全のため**自動的にモックモード**で起動します。

### 2. クライアントの起動

起動用スクリプト `run.sh` を実行します。このスクリプトは、初回起動時に自動的に Python 仮想環境 (`.venv`) を構築し、依存パッケージのインストールを行ってからアプリを起動します。

#### ■ 通常モード (本番API接続 - 書き込み可能)
```bash
./run.sh
```

#### ■ 読み込み専用モード (参照操作のみ)
新規投稿の送信、いいね付与、返信などの書き込み機能を禁止し、参照操作のみに制限したい場合は、`--read-only` フラグを付与して起動してください。
```bash
./run.sh --read-only
```

#### ■ モックモード (書き込みを含む全機能のテスト用)
新規投稿の送信、いいね付与、返信などの書き込み機能をテストする場合は、必ず `--mock` フラグを付与して起動してください。
```bash
./run.sh --mock
```

## 操作方法

### 1. キーボード・ショートカット

| キー | アクション |
|:---|:---|
| `q` | アプリケーションの終了 |
| `n` | 新規ルート投稿の作成 (文字数カウンター & 500文字制限バリデーション付き) |
| `r` | 画面情報の再読み込み |
| `s` | 設定画面を開く (自動更新の間隔・オンオフを変更) |
| `Tab` | タブ (タイムライン / 自分の投稿 / ヘルプ) の切り替え |
| `Enter` | タイムラインでフォーカスしている投稿の会話スレッドを表示 |
| `Esc` / `Backspace` | スレッド詳細表示からタイムライン表示に戻る |
| `Ctrl + S` | 投稿作成モーダルでの送信 |
| `Esc` (モーダル内) | 投稿作成モーダルのキャンセル・閉じる |

### 2. マウス操作
- **タブ切り替え**: 上部のタブバー (`[タイムライン]`, `[自分の投稿]`, `[ヘルプ]`) をクリックして表示を切り替えます。
- **いいね (♥️)**: 投稿カード左下の `[Like / Liked]` ボタンをクリックしてトグルします（※読み込み専用モードでは無効）。
- **返信 (💬)**: `[Reply]` ボタンをクリックして返信モーダルを起動します（※読み込み専用モードでは無効）。
- **詳細スレッド (🔍)**: `[View Thread]` ボタンをクリックしてスレッドツリーを展開します。
- **スクロール**: リスト上でのマウスホイール操作による縦スクロールに対応しています。
